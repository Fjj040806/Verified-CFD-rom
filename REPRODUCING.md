# Reproducing the project

## Environment and demonstration

Install `requirements.txt`, then run `python scripts/demo.py` from the project directory. See `environment-record.json` for the versions actually used in the release check. That record is evidence of one working environment, not a universal dependency lock.

Core dependencies: NumPy, SciPy and Matplotlib. The demonstration uses 301 settled, float64 P2 velocity snapshots from time 27 to 30 with the consistent mass matrix. The model ranks are frozen from the earlier validation study. The plot displays a POD coefficient; complete velocity errors use the full mass-weighted state.

## Core numerical and ROM checks

```bash
PYTHONPATH=src python -m unittest discover -s tests -p test_mac.py -v
PYTHONPATH=src python -m unittest discover -s tests -p test_flow.py -v
PYTHONPATH=src python -m unittest discover -s tests -p test_cavity.py -v
PYTHONPATH=src python -m unittest discover -s tests -p test_rom.py -v
PYTHONPATH=src python experiments/verify_phase1.py
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/verify_phase2.py
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/verify_phase3.py
```

These checks do not need Gmsh. Full-suite cylinder tests require the optional FEM environment.

## Cylinder dependencies and expensive reruns

```bash
python -m pip install -r requirements-cylinder.txt
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python -m unittest discover -s tests -v
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/verify_phase4.py
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/audit_phase4.py
```

Gmsh needs OS shared libraries, including `libGLU.so.1` and, on some Linux installations, `libXft.so.2`. Install the relevant system packages when required. The release does not bundle system libraries. Optional `vtk` enables the native export reader test; it is otherwise skipped. `meshio` is included in the cylinder requirements.

To regenerate the selected transient baseline:

```bash
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/run_phase4b.py --name coarse --dt .01 --end 30
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/run_phase4b.py --name coarse-half --dt .005 --end 30 --restart results/phase4b/coarse-checkpoint25.npz --tol 1e-6 --snapshot-dt .01
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/verify_bdf2.py
```

These are full nonlinear CFD runs and are substantially more expensive than the stored-data analysis. The first command generates the restart checkpoint required by the second. BE is used at startup/restart before BDF2. Saved snapshots include a warmup interval; ROM analysis restricts to time at least 27. The coarse exploratory data originally used float32; the reproduction script now writes float64. Do not expect byte-for-byte reproduction of that earlier storage format.

## Stored-data studies

```bash
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/analyze_phase5.py
python experiments/visualize_phase5.py
PYTHONPATH=src OPENBLAS_NUM_THREADS=1 python experiments/analyze_phase6.py
```

These regenerate the report's ROM figures and JSON results. Their output paths are fixed inside `results/phase5`, `results/phase6`, and `figures`.

## Full-archive features

`experiments/analyze_phase4b.py` and `experiments/visualize_phase4b.py` expect the additional coarse/refined histories and fields retained in the full archive, or regenerated by the Phase4B commands in its stage report. The lightweight package includes the computed shedding GIF but does not include every input required to regenerate it. See `reports/paraview-guide.md` for VTK use; a ParaView GUI is optional and was not used for the export validation.

## Meaning of the measurements

POD reconstruction projects observed fields. DMD prediction starts from the last training frame and never resets on validation/test truth. Fluctuation error uses the relevant training mean; total-field error is also reported. Common-time cadence controls evaluate four identical future times, so they do not resolve every within-cycle error. Use the stage reports before interpreting any number as a general convergence or robustness result.
